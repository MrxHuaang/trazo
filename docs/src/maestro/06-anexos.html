Anexos

Anexo A · Entorno de desarrollo paso a paso (Windows)

1. Instalar herramientas

  1. Git (git-scm.com) y Node.js LTS con npm (nodejs.org). Verificar: node -v, npm -v, git --version.
  2. VS Code con las extensiones Expo Tools, ESLint y Tailwind CSS IntelliSense (autocompleta las clases de NativeWind).
  3. Android Studio: instalar el SDK de Android y crear el emulador: Device Manager → Create device → Pixel 8 → imagen reciente “Google Play” (Android 15 o superior). Si Expo no encuentra el SDK, agregar ANDROID_HOME y la carpeta platform-tools (donde está adb) al PATH.

2. Clonar y ejecutar

git clone https://github.com/MrxHuaang/trazo.git
cd trazo
git switch feat/mvp-sprints
npm install
npx expo start            # tecla "a": abre el emulador Pixel 8 con Expo Go

No hay variables de entorno ni cuentas que configurar: los datos viven en SQLite dentro del teléfono y los servicios remotos (USGS, OpenStreetMap) son públicos.

3. Expo Go 58 en el emulador

  • La primera vez, npx expo start instala Expo Go en el emulador. Debe ser la versión 58 (se usó la 58.0.5).
  • Si el emulador abre un Expo Go viejo, es porque el arranque rápido restauró una instantánea anterior: hacer Cold Boot desde Device Manager y dejar que Expo instale la versión compatible.
  • Si Expo Go se queda en “Downloading 100 %”, redirigir el puerto y abrir la dirección local:
adb reverse tcp:8081 tcp:8081
# en Expo Go: "Enter URL manually" → exp://127.0.0.1:8081

4. iPhone (opcional)

Instalar Expo Go desde el App Store. Con el PC y el iPhone en la misma red Wi-Fi, escanear con la cámara el QR que muestra npx expo start; en otra red, usar npx expo start --tunnel. No se necesita Mac ni cuenta de Apple.

5. Verificación

npx tsc --noEmit          # tipos (TypeScript estricto)
npx expo lint             # estilo (ESLint de Expo)
  • La app abre en el emulador Pixel 8 con Expo Go 58 y muestra la bienvenida.
  • “Explorar con datos de demostración” carga 12 pacientes ficticios con citas, pagos y jornadas.
  • Con internet, Solidario muestra los sismos recientes y el mapa de jornadas.
  • Tipos y lint terminan sin errores.

Anexo C · Borrador de autorización de tratamiento de datos

Autorización para el tratamiento de datos personales Borrador · no se usa con personas reales

Yo, ______________________, identificado(a) con ______________________, autorizo de manera previa, expresa e informada a [nombre de la psicóloga], como Responsable del Tratamiento, para recolectar, almacenar, usar, actualizar y suprimir mis datos personales, incluidos datos sensibles relativos a mi salud, con las siguientes finalidades:

  1. Agendar y gestionar mis citas.
  2. Enviarme recordatorios y comunicaciones sobre mi atención por WhatsApp o llamada.
  3. Llevar el registro de mi proceso de atención psicológica.
  4. Gestionar pagos y tarifas, incluidas tarifas solidarias.
  5. Elaborar estadísticas anónimas sobre la atención brindada a personas afectadas por el sismo del 10 de agosto de 2026.

Declaro que se me informó que: el suministro de datos sensibles es facultativo y no estoy obligado(a) a autorizar su tratamiento; mis datos se guardan en el teléfono de la profesional, protegido con bloqueo, y no se envían a servidores de terceros; como titular tengo derecho a conocer, actualizar, rectificar y solicitar la supresión de mis datos y a revocar esta autorización, salvo cuando exista un deber legal de conservarlos; puedo ejercer estos derechos escribiendo a [correo de contacto].

Fecha: ____________ · Firma o aceptación: ____________ · Si es menor de edad, representante legal: ____________

Texto de trabajo basado en la Ley 1581 de 2012; no constituye asesoría legal. En la app, la autorización se registra por paciente con su fecha y la versión del texto aceptado.
