Resumen del avance

Trazo es una app móvil en React Native + Expo para organizar la consulta de una psicóloga independiente (agenda, pacientes, recordatorios, pagos, notas) con un módulo solidario para atender a personas afectadas por el sismo del 10 de agosto de 2026 en Pereira. A la fecha están listos el documento maestro, el sistema visual, la capa de datos y la pantalla principal funcionando en el emulador; los módulos restantes están en desarrollo en ramas separadas.

Cómo ejecutar el proyecto

git clone https://github.com/MrxHuaang/trazo.git
cd trazo
git switch feat/mvp-sprints
npm install
npx expo start            # tecla "a": abre el emulador Android con Expo Go 58

# Si Expo Go se queda en "Downloading 100%" en el emulador:
adb reverse tcp:8081 tcp:8081      # y abrir exp://127.0.0.1:8081

npx tsc --noEmit          # tipos
npx expo lint             # estilo

La app carga datos ficticios de demostración la primera vez (12 pacientes, citas de dos semanas atrás a dos adelante, pagos, jornadas y líneas de ayuda). Ningún dato corresponde a personas reales.
